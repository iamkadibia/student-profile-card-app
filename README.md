# Student Profile Card App

This project was built as part of KodeCamp 6.0 Stage 2 promotional tasks.

## Overview

A React application that displays student profile cards using reusable components and props-based architecture.

## Features

- Student profile cards rendered dynamically
- Reusable components (Header, Badge, StatBar, StudentCard, StudentList)
- Class average calculated using `reduce()`
- Grade system based on student scores (A–F)
- Conditional rendering for:
  - Active / Inactive students
  - Empty skills list
- Visual score bar with dynamic colors

## Components

- Header.jsx
- StudentList.jsx
- StudentCard.jsx
- Badge.jsx
- StatBar.jsx

## How to run locally

npm install  
npm run dev

## Build for production

npm run build

## Deployment

This project is deployed using Vercel.
